Hermes Sanji Drive

Hermes Sanji Drive is a personal, single-user automation connection operated by the account owner (geongeon0422@gmail.com). It lets the owner's private Hermes assistant profile "Sanji" read the owner's blog automation materials (weekly blog statistics, account screenshots, manuscripts) and add new blog manuscripts and images, all inside one Google Drive folder chosen by the owner ("블로그 자동화").

Hermes Sanji Drive는 계정 소유자 본인만 사용하는 개인 자동화 연결입니다. 개인 Hermes 비서의 Sanji 프로필이 소유자의 '블로그 자동화' 폴더 안에 있는 자료(주간 블로그 통계, 계좌 스크린샷, 원고)를 읽고, 같은 폴더 안에 새 원고와 이미지를 추가하는 데만 사용합니다.

Privacy Policy / 개인정보처리방침

  • Scopes: https://www.googleapis.com/auth/drive.readonly (read) and https://www.googleapis.com/auth/drive.file (create new files in folders the owner selected). Google does not offer a folder-limited scope, so the software itself only reads items whose parent chain is inside the owner's "블로그 자동화" folder and refuses everything else.
  • Use: read blog statistics, screenshots and manuscripts to suggest topics and write drafts; create new date/post folders and upload new manuscripts and images; read back name, parent, size and checksums to verify uploads.
  • The app never modifies, overwrites, deletes, trashes, shares or changes permissions of existing files.
  • Storage: OAuth credentials are stored only on the owner's private server with restricted file permissions. Downloaded copies are kept in a private working directory on that server for processing only.
  • Sharing: data is not sold, shared, or transferred to third parties, and is not used for advertising or to train generalized AI/ML models. Content may be processed by the AI model provider that runs the owner's private assistant solely to perform the owner's requests.
  • Revocation: access can be revoked at any time at Google Account permissions.
  • 범위: drive.readonly(읽기)와 drive.file(새 파일 추가)을 사용합니다. Google은 폴더 단위 권한을 제공하지 않으므로 프로그램에서 '블로그 자동화' 폴더 밖 항목은 거부합니다. 기존 파일의 수정·삭제·공유는 하지 않으며, 데이터를 제3자에게 판매·공유하거나 광고·AI 모델 학습에 사용하지 않습니다.

Google API Services usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
