Hermes Sanji Drive

Hermes Sanji Drive is a personal, single-user automation connection operated by the account owner (geongeon0422@gmail.com). It lets the owner's private Hermes assistant profile "Sanji" upload the owner's own blog manuscripts and images into one Google Drive folder that the owner explicitly selected.

Hermes Sanji Drive는 계정 소유자 본인만 사용하는 개인 자동화 연결입니다. 개인 Hermes 비서의 Sanji 프로필이 소유자가 직접 선택한 Google Drive 폴더에 소유자 본인의 블로그 원고와 이미지를 업로드하는 데만 사용합니다.

Privacy Policy / 개인정보처리방침

  • Scope: only https://www.googleapis.com/auth/drive.file. The app can access only files and folders it created or that the owner explicitly selected with Google Picker. It does not read the rest of Google Drive, Gmail, Calendar, or contacts.
  • Use: create date and post folders, upload manuscripts and images, and read back file name, parent folder, size and checksums to verify uploads.
  • Storage: OAuth credentials are stored only on the owner's private server with restricted file permissions. Uploaded content stays in the owner's own Google Drive.
  • Sharing: data is not sold, shared, or transferred to third parties, and is not used for advertising or to train generalized AI/ML models.
  • No deletion, public sharing, or permission changes are performed by this app.
  • Revocation: access can be revoked at any time at Google Account permissions.
  • 범위: drive.file 권한만 사용하며, 앱이 만들었거나 소유자가 선택한 파일·폴더에만 접근합니다. 데이터는 제3자에게 판매·공유하지 않고 광고나 AI 모델 학습에 사용하지 않습니다.

Google API Services usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
